# Fiktive Testimmobilien

`Testimmobilien.json` enthält sechs vollständig als TEST gekennzeichnete Fälle im nativen Sicherungsformat. Alle Grundstücke, Adressen, Mieten, Quellen und Marktansätze sind synthetisch.

1. Einfamilienhaus mit PV und Garage.
2. Vermietete Eigentumswohnung.
3. Mehrfamilienhaus mit sechs Wohnungen und aktiver Mietrolle.
4. Sanierungsbedürftiges Altbauhaus mit getrenntem Energieszenario.
5. Teilwohnrecht und Beleihung bei kurzer Restnutzung.
6. Absichtlich unvollständige Erstaufnahme als Entwurf.

In der App können die Fälle unter **Mehr → Testimmobilien hinzufügen** ergänzt werden. Vorhandene Objekte werden nicht verändert; erneutes Betätigen fügt keine Duplikate hinzu. Für die einmalige betreute Gerätebefüllung existiert zusätzlich das Startargument `--testimmobilien-einspielen`.

Die Daten dienen ausschließlich dazu, die Bedienung auszuprobieren. Die Beträge sind keine Bewertungen realer Immobilien. Die Statusprüfungen stehen in `Testimmobilien-Prüfung.json`.
